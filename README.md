# What Kait Is Reading

A personal library built with React 19, React Three Fiber 9, Three.js and Vite. This replaces the earlier desk portfolio. A fixed camera faces four individually modeled books between split agate bookends. Selecting a book opens a full-screen reading room with its 3D form, notes, takeaways, questions, and a bookstore link.

## Run

Node 22.12+ is required (validated with Node 24.19.0).

```sh
cd /workspace/Portfolio
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev -- --port 5173
```

`npm run build` creates the static deployment in `dist/`; `npm run preview -- --port 5173` serves that build. No backend, authentication, API keys or external runtime font service is needed. A WebGL-capable browser displays the models. The reading list also exposes every book through HTML controls when WebGL is unavailable.

## Design and references

- The user's bookend reference shows complementary agate halves with pale crystalline centers, blue-green bands, and a thin tan rind. The bookends use extruded 3D silhouettes and a reference-derived texture generated by the session image tool. That texture is an approximation, not an untouched photograph of the exact product. Its original is `/workspace/generated_images/exec-874e00f8-25d9-4f39-a642-b877d5a0e438.png`.
- The user requested wide, very heavy uppercase headings and fine serif body text. The implementation uses self-hosted **Unbounded** and **Cormorant Garamond** from the Google Fonts repository. These are stylistic matches, not confirmed identification of the screenshot's proprietary typefaces. Both OFL licenses are included in `public/fonts/`.
- The camera is fixed; there are no orbit, pan, zoom or parallax controls. Hover moves just the selected book slightly forward. Selection opens a separate 3D book view. Reduced-motion preferences suppress decorative transitions and use immediate object positioning. The render loop uses `demand` and invalidates only during object transitions.

## React Three Fiber source reviewed

The requested repository [pmndrs/react-three-fiber](https://github.com/pmndrs/react-three-fiber) was cloned read-only to `/tmp/kait-library-r3f` at commit `d74622ea8ed717f7212d7e19d65ff3e325508389`. Read its README and `docs/API/canvas.mdx`, `events.mdx`, `hooks.mdx`, plus the on-demand-rendering guidance in `docs/advanced/scaling-performance.mdx`.

The implementation follows its React 19 / Fiber 9 pairing; `Canvas` owns the renderer and fixed camera; mesh events handle pointer selection and propagation; `useFrame` mutates object transforms without React state updates per frame; `invalidate` runs short demand-rendered transitions; resource lifecycles dispose generated textures.
